# ASCEND Pokémon Champions Hub

Centro competitivo de ASCEND para Pokémon Champions.

## Estructura

- `index.html` — estructura principal.
- `styles.css` — estilos visuales.
- `app.js` — interacción, audio, navegación, filtros, modales y calculadora.
- `pokemon.json` — datos de Pokémon, tiers, builds y roles.
- `teams.json` — equipos, matchups y meta report.
- `audio/` — carpeta reservada para sonidos o música.
- `images/` — carpeta reservada para logos e imágenes locales.

## Publicación

Sube todos estos archivos y carpetas al repositorio de GitHub Pages.
